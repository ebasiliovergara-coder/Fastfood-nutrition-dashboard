# Fastfood-nutrition-dashboard
Proyecto de Limpieza y visualización de datos cuyo objetivo es comparar y encontrar cuales son las mejores opciones de alimentos en las principales cadenas de Fastfood en EUA. El dataset proviene de Kaggle ("Fastfood Nutrition", publicado por Ulrik Thyge Pedersen) e incluye información nutricional de 515 productos de 8 cadenas: McDonald's, Burger King, Taco Bell, Subway, Arby's, Sonic, Dairy Queen y Chick-fil-A. Tiene 17 variables, entre ellas calorías, grasas, sodio, carbohidratos, fibra y proteína. Después de la limpieza quedaron 513 productos.
